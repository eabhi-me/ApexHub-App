# Flat Design UI Skill

Use Flat Design principles when creating or modifying UI.

## Core principles

- Use clean, simple visual hierarchy.
- Avoid unnecessary gradients, textures, and realistic effects.
- Prefer solid colors and simple shapes.
- Use clear typography and strong spacing.
- Keep interfaces visually lightweight.
- Use meaningful contrast between backgrounds, surfaces, text, and interactive elements.
- Prefer simple icons and illustrations.
- Avoid excessive shadows and skeuomorphic effects.
- Keep components consistent across the application.

## Layout

- Use generous whitespace.
- Establish a clear spacing system.
- Maintain consistent alignment.
- Use grids and cards where appropriate.
- Keep navigation and primary actions obvious.

## Components

Buttons:
- Simple solid or outlined buttons.
- Clear hover/focus states.
- Avoid excessive decoration.

Cards:
- Clean surfaces.
- Minimal borders or subtle shadows when needed.
- Consistent padding and spacing.

Forms:
- Clear labels.
- Strong visual hierarchy.
- Obvious focus states.
- Accessible error and success states.

## Typography

- Use readable modern fonts.
- Establish clear heading/body hierarchy.
- Avoid excessive font weights and decorative typography.

## Color

- Use a restrained palette.
- Maintain accessible contrast.
- Use accent colors primarily for actions and important information.

## Implementation

When writing frontend code:
- Keep CSS/component structure clean.
- Prefer reusable design tokens.
- Maintain responsive behavior.
- Ensure accessibility.
- Do not introduce gradients, glassmorphism, or 3D effects unless explicitly requested.
